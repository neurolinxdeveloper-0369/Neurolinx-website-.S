# Neurolinx Global Brand & UI Design Tokens

## Palette Configuration
- Primary Brand Red: `#C81623` (Accents, primary action CTAs, active status, borders on focus)
- Industrial Charcoal: `#4B4C4C` (Secondary typography, borders, card divider strokes, subtle icons)
- Pure Light: `#FFFFFF` (Headings, primary typography, high-contrast states)
- Deep Slate (Background): `#0D0E0F` (Base dark mode canvas)
- Surface Elevated: `#161719` (Cards, industrial panel containers)

## Typography
- Display / Headings: `Space Grotesk` or `Inter` (Font-weight: 700 / 800)
- Technical Data / Specs / Code: `JetBrains Mono` (Font-weight: 400 / 500)
- Body Text: `Inter` (Font-weight: 400 / 500)

## Component Rules
- Border Radius: Sharp to semi-rounded (`rounded-none` to `rounded-sm` max 4px for industrial engineering feel).
- Drop Shadows: Minimal or zero ambient glow; rely on crisp 1px borders (`border border-[#4B4C4C]/40`).
- Accent Borders: Top/Left highlight ribbons in `#C81623`.
