## Rules

1. Do not contradict an Accepted ADR in feature docs without updating the ADR and [00_DOCUMENTATION_STATUS.md](../00_DOCUMENTATION_STATUS.md).
2. Prefer linking to the ADR rather than restating the full rationale elsewhere.
3. Status values: Proposed | Accepted | Superseded | Deprecated.
