Non-UV Disinfection Light Models - Image Naming Guide
======================================================
Place product images in this directory with the following filenames:

1.  PSR 24W     -> psr-24w.jpg (or .png / .webp)
2.  PSR 18W     -> psr-18w.jpg
3.  PSR 15W     -> psr-15w.jpg
4.  PSR 12W     -> psr-12w.jpg
5.  PSQ 18W     -> psq-18w.jpg
6.  PSQ 12W     -> psq-12w.jpg
7.  RDSR 12W    -> rdsr-12w.jpg
8.  RDCR 24W    -> rdcr-24w.jpg
9.  RDCR 18W    -> rdcr-18w.jpg
10. RDCR 12W    -> rdcr-12w.jpg
11. RDCR 6W     -> rdcr-6w.jpg
12. RDCQ 30W    -> rdcq-30w.jpg
13. RDCQ 24W    -> rdcq-24w.jpg
14. RDCQ 18W    -> rdcq-18w.jpg
15. RD PCR 24W  -> rdpcr-24w.jpg
16. RD PCQ 24W  -> rdpcq-24w.jpg

Any image placed here will automatically show up on the website!
